# 玄枢 · 案例知识工作台

一个面向占星、星盘与塔罗实践者的个人知识与案例操作系统。

## 当前版本

- 用自然语言讲述咨询或研究经过
- 自动生成可编辑的结构化案例草稿
- 按占星、塔罗、主题与状态管理案例
- 全局搜索、回访状态与洞察统计
- 浏览器本地存储，支持 JSON 导出
- 响应式桌面和移动端界面
- iPhone / iPad 主屏幕安装（PWA）与离线应用外壳
- 批量导入 PDF、EPUB、文本、Markdown 和图片教材
- 教材文件保存于设备 IndexedDB，支持分类、阅读、下载和删除
- 整理 AI 支持案例、知识卡、判断规则和内容草稿的结构化
- 181 张五层知识卡：占星 71、塔罗 92、数字命理 18
- 完整覆盖塔罗 78 张牌，以及互溶接纳、尊贵、定位星链、才能兑现、得财结构与 12 类星盘格局
- iPhone 调用系统分享菜单，把 PDF、EPUB 等文件发送到微信读书
- 五库闭环：Knowledge、Cases、Rules、Errors、Content
- 案例统一采用“象征 → 现实机制 → 行动”三层模型
- 案例可直接生成带来源 Case ID 的内容选题

完整结构见 [`玄学OS-V1数据库设计.md`](./玄学OS-V1数据库设计.md)。

电脑预览可直接双击 `index.html`；要从页面打开内置 PDF，请使用本地 HTTP 服务。PWA 安装和离线能力需要通过 HTTPS 部署，在 iPhone Safari 中打开网址，点击分享，再选择“添加到主屏幕”。

私人教材只保存在用户设备，不进入公开仓库，也不会发送给整理 AI。

## 数据结构

每个案例包含：标题、领域、人物匿名代号、主题、核心问题、使用技法、关键洞察、待验证/回访点、原始叙述、状态与日期。

## 整理 AI

前端已接入“整理 AI”工作台，后端示例位于 `worker/`。它通过 OpenAI Responses API 完成案例、知识卡、判断规则和内容草稿的结构化。教材不会上传给 AI。API 密钥只保存在后端环境变量中，不能写入浏览器或公开 GitHub。

部署方法见 [`整理AI接入说明.md`](./整理AI接入说明.md)。后续还可加入用户登录、语音录入、PDF.js、epub.js、知识节点自动关联和回访提醒。

## 开源组件规划

- [Mozilla PDF.js](https://github.com/mozilla/pdf.js)：PDF 阅读与文本提取，Apache-2.0
- [FuturePress epub.js](https://github.com/futurepress/epub.js)：EPUB 阅读，BSD 类许可证

当前原型没有直接打包第三方组件，后续引入时会一并保留许可证文件和版本记录。

## 微信读书

资料卡和阅读器都有“传到微信读书”入口。在 iPhone 上点击后，会打开系统分享菜单；选择“微信读书”即可导入。网页无法强制指定分享目标，因此微信读书未出现在菜单时，可以先选择“存储到文件”，再从微信读书书架的本地导入功能选取。

没有使用未公开的微信读书上传接口，也不会读取或保存微信账号、Cookie。

## iPhone 安装

公开 App 外壳由 GitHub Pages 自动部署，私人教材不会进入公开仓库。线上打开后，在 iPhone Safari 点击“分享”→“添加到主屏幕”。之后可在设备内通过“导入教材”添加 PDF 或 EPUB；整理 AI 与教材相互独立。
